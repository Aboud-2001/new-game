# 🧠 لعبة الذاكرة (Memory Game)

لعبة ذاكرة بسيطة وممتعة مبنية بـ HTML و CSS و JavaScript!

## 📋 المميزات

- ✅ واجهة مستخدم جميلة وسهلة الاستخدام
- ✅ تتبع المحاولات والأزواج المجدة
- ✅ مؤقت لقياس الوقت
- ✅ دعم الجوال (Responsive)
- ✅ واجهة باللغة العربية

## 🎮 كيفية اللعب

1. اضغط على البطاقات للبحث عن الأزواج المتطابقة
2. تذكر موقع كل رمز
3. ابحث عن جميع الأزواج بأقل محاولات ووقت ممكن
4. اضغط "لعبة جديدة" لإعادة التشغيل

## 🚀 كيفية التشغيل

### الطريقة 1: التشغيل المباشر
1. افتح ملف `index.html` في متصفحك

### الطريقة 2: GitHub Pages
1. اذهب إلى إعدادات المستودع (Settings)
2. اختر Pages من القائمة الجانبية
3. اختر main branch
4. الآن يمكنك الوصول للعبة من رابط GitHub Pages

## 📁 الملفات

- `index.html` - هيكل الصفحة
- `style.css` - تنسيق وتصميم اللعبة
- `script.js` - منطق اللعبة

## 💻 التقنيات المستخدمة

- HTML5
- CSS3 (Grid, Flexbox, Gradients)
- JavaScript (ES6+)
